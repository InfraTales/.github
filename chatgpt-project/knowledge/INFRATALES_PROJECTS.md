# InfraTales Repository Notes

This file should not be used as a static catalog of "production-ready" repositories.

InfraTales repository truth changes over time and should be derived from:

- the live GitHub organization inventory
- each repository's declared type and status
- the standards in `InfraTales/.github`

Use these documents instead of a frozen project list:

- `REPO_TYPES.md`
- `PUBLIC_REPO_STANDARD.md`
- `REPO_REVIEW_SCORECARD.md`
- `PUBLIC_RELEASE_CHECKLIST.md`
- `LICENSE_POLICY.md`
