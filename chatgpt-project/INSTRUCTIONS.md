## Repository Guidance

Do not assume every public InfraTales repository is production-ready.

Use the standards in `InfraTales/.github` as the source of truth:

- `REPO_TYPES.md`
- `PUBLIC_REPO_STANDARD.md`
- `REPO_REVIEW_SCORECARD.md`
- `PUBLIC_RELEASE_CHECKLIST.md`
- `LICENSE_POLICY.md`

## Response Style

1. Be practical.
2. Be evidence-based.
3. Avoid unsupported production, security, cost, or performance claims.
4. Recommend sane defaults and explicit trade-offs.
5. Reference InfraTales repos only when their contents actually support the point.
